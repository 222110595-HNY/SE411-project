# IT Asset Manager — SE411 Project

A full-stack app for managing a company's **computer assets** (laptops, desktops, servers, tablets).

- **Part 1** — React front-end (`src/`). Navigation, add/view/update/delete, search + status filter, dashboard, About page.


## Features
- Navigation menu: Dashboard · Assets · Add Asset · About
- Add, view, update and delete assets (persisted through the REST API)
- Search (tag, type, brand, model, serial, assignee) + filter by status
- Dashboard with counts per status and total value
- About page listing the team (name, student ID)
- Paginated REST API backed by Spring Data JDBC + H2
