# IT Asset Manager — SE411 Project Part 1

A React front-end for managing a company's **computer assets** (laptops, desktops, servers, tablets).
Data is kept in memory as a collection of objects (no database in Part 1).

## Features
- Navigation menu: Dashboard · Assets · Add Asset · About
- Add, view, update and delete assets
- Search (tag, brand, model, serial, assignee) + filter by status
- Dashboard with counts per status and total value
- About page listing the team (name, student ID)

## Run
```bash
npm install
npm run dev     # http://localhost:5173
npm test        # unit + UI tests (Vitest + Testing Library)
npm run build
```
